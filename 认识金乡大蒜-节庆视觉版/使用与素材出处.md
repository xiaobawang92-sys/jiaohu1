# 认识金乡大蒜

## 展馆触屏使用

解压后用 Chrome 或 Edge 打开 `index.html`。以 16∶9 横屏全屏展示，首页点按「触摸开始」进入主题总览，四张主题卡片均可点按。各主题顶部可切换板块或返回总览，标题区也可进入下一主题。图文、热点、农时、加工工序和地图案例可离线操作，外部出处链接需要联网。

如果更新 GitHub Pages，将 `index.html`、`.nojekyll` 和整个「素材」目录上传到原站点的发布目录，并保持目录层级。

## 节庆视觉

待机页采用金乡大蒜节原设计标识。「拔蒜」人物及手持蒜株取自「蒜农辅助图形-10.svg」，右侧花形取自「海报集合-02.svg」。拱形和弧形田垄以原主视觉海报、灯杆旗为依据，配色参考室内吊旗。主体色不叠加到科普实拍图上。

## 照片和资料出处

- **一头金乡蒜**：[山东仁禾食品保鲜大蒜](https://www.sdrenhefood.com/products/baoxian/8.html)为金乡企业产品实拍，供观察代表性白皮蒜外形。形态、产地与代表性品质依据[国家知识产权局金乡大蒜介绍](https://english.cnipa.gov.cn/module/download/down.jsp?colID=1364&i_ID=150286)、[《地理标志产品 金乡大蒜》标准信息](https://std.samr.gov.cn/gb/search/gbDetailed?id=71F772D7FC38D3A7E05397BE0A0AB82A)及[济宁市政府刊载的金乡地理标志产品保护办法](https://www.jining.gov.cn/jpolicypub/jpolicy_file/filedata/2025/02/08/3a915bef8e474e838ffb0c2cbdb12925.pdf)。切碎后产生大蒜素属于通用生物原理，参照[相关研究](https://www.mdpi.com/2311-5637/8/11/653)。
- **蒜田里的生长**：金乡蒜田照片来自[大众新闻报道（新浪转载）](https://news.sina.com.cn/zx/gj/2025-12-20/doc-inhcmstm1329541.shtml)，金乡机械采收来自[济宁市农机中心](https://www.jining.gov.cn/art/2024/5/16/art_78317_2870981.html)，人工播种、蒜薹与蒜株基部三张配图取自[肯塔基州立大学农业推广资料《Garlic》](https://kysu.edu/documents/college-of-agriculture-communities-the-sciences/garlic_2019.pdf)，用于观察种植动作和形态。农时及金乡田间作业参照[农业农村部刊载的农民日报产区报道](https://scs.moa.gov.cn/gzdt/202411/t20241105_6465731.htm)。部分阶段的月份随品种和田间长势变化。
- **从蒜田到餐盘**：鲜蒜及[脱水蒜片](https://www.sdrenhefood.com/products/tuoshui/13.html)、[蒜粉](https://www.sdrenhefood.com/products/tuoshui/5.html)、[黑蒜](https://www.sdrenhefood.com/products/heisuan/12.html)来自金乡企业山东仁禾食品的产品照片。黑蒜变色原理参照[加工过程实验研究](https://www.mdpi.com/2311-5637/8/11/653)。加工前后照片展示不同产品形态。
- **一头蒜的远行**：[中新网实地报道](https://www.chinanews.com.cn/cj/2026/02-01/10563189.shtml)记录了金乡崔口村分拣现场（周艺伟 摄），冷库出库整理照片及销往越南的例子来自[农民日报实地报道](https://scs.moa.gov.cn/gzdt/202411/t20241105_6465731.htm)。袋装鲜蒜由山东仁禾食品展示。印度尼西亚案例见[农业农村部刊载的2026年9月会商材料](https://scs.moa.gov.cn/jcyj/202610/t20261009_6488437.htm)。地图基于 [Natural Earth 1:110m Land](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/) 绘制，标明目的地案例，虚线表示贸易联系。检验环节参考[济宁市跨境贸易便利化手册](https://www.jining.gov.cn/art/2021/10/27/art_71695_2735907.html)。
- 首屏照片入口受[辛辛那提博物馆中心案例](https://sebastian-design.com/project/cincinatti-museum-center)启发。沿用金乡大蒜节标识和原设计的蒜心白、浅紫、浅绿。蒜头产品及有署名的现场素材来自实拍。分选、蒜田、晾晒和加工照做了媒体水印清理，原始出处见上方及本页末尾。
- 四张菜品和用途图（蒜瓣烧鸡、蒜片蔬菜汤、蒜粉腌料、黑蒜酱）以及鲜蒜样品检查图为生成示意。
